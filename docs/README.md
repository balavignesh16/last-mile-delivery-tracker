lands: `architecture.md`, `database.md`, `api.md`, `rate-engine.md`,
`assignment-engine.md`, `order-lifecycle.md`, `failed-delivery.md`,

write-up (≤ 800 words).

None of these exist yet as of M01 — the root [README.md](../README.md)
carries M01's own documentation directly, and will link into this
directory as each file is written.
