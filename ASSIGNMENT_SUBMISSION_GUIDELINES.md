# Preferred Submission Format

## Primary: GitHub Repository Link

The preferred submission format is a **GitHub Repository link**.

Requirements:

- Branch must be `main`.
- Repository must be public / open-source.
- Repository size should be within GitHub limits.
- Repository must be fully downloadable.

## Alternative: Google Drive Link

An alternative submission method is a Google Drive link.

Requirements:

- Must be publicly accessible / not protected.
- Folder/file should be downloadable.
- File size should not exceed Google Drive limits.
- Ideally, file size should be less than 1 GB.

# Project Structure

Submit **only the basic application** with all required assignment and project code files.

Do not include unnecessary files.

The guidelines specifically identify the following as files/folders that should not be included:

- `node_modules` or equivalent dependency folders
- `.env` or other sensitive configuration files
- Build artifacts such as:
  - `dist/`
  - `.next/`
  - `out/`
- Temporary/editor-specific files such as:
  - `.vscode/`
  - `.idea/`

# Packages & Dependencies

The guidelines state:

- **Do not add extra modules or package files.**
- Use only what is strictly required for the assignment/project.
- Keep dependencies minimal and native whenever possible.

# Checklist Before Submission

Before submitting, ensure:

- [ ] The app runs without errors.
- [ ] Code files are properly structured and named.
- [ ] No unnecessary/temporary files are committed.
- [ ] Branch name is set to `main`.
- [ ] Repository or Google Drive link is publicly accessible and downloadable.
- [ ] Submission size is within GitHub / Google Drive limits.
- [ ] Proper documentation or comments are included where necessary.

# How to Submit

## GitHub

1. Push your code to a GitHub repository.
2. Branch: `main`.
3. Repository must be public / open-source.
4. Repository must be downloadable.
5. Repository size must be within GitHub limits.
6. Share the GitHub link according to the assignment submission instructions.

The document provides this example format:

```text
https://github.com/username/project-name
```

## Google Drive

If using Google Drive:

1. Ensure the folder/file is publicly accessible.
2. Ensure it is downloadable.
3. Keep it within Google Drive size limits.
4. The document suggests ideally keeping it below 1 GB.
5. Share the link according to the assignment submission instructions.

The document provides this example format:

```text
https://drive.google.com/drive/folders/...
```
